# Visualizaciones — Dataset NFL plays.csv (2017)

Gráficas generadas automáticamente a partir de `data/plays.csv`.  
Para regenerarlas: `python3 visualizaciones/generar_graficas.py`

---

## Índice de gráficas

| Archivo | Qué muestra |
|---|---|
| `01_tipo_jugadas.png` | Pie chart: proporción de pases, carreras y jugadas especiales |
| `02_formaciones_ofensivas.png` | Barras horizontales: uso de cada formación ofensiva |
| `03_resultado_pases.png` | Barras: completo / incompleto / sack / scramble / interceptado |
| `04_distribucion_yardas.png` | Histograma de yardas ganadas por jugada (con mediana y promedio) |
| `05_yardas_por_down.png` | Boxplot: distribución de yardas según el down |
| `06_defensores_caja_vs_yardas.png` | Yardas promedio ganadas según defensores en la caja |
| `07_jugadas_por_cuarto.png` | Barras: cantidad de jugadas por cuarto (Q1–Q4 + OT) |
| `08_paquetes_defensivos.png` | Barras horizontales: paquetes defensivos más frecuentes |
| `09_penalizaciones_por_equipo.png` | Top 15 equipos con más penalizaciones en posesión |
| `10_heatmap_formacion_vs_pase.png` | Heatmap: resultado del pase (%) según formación ofensiva |
| `11_evolucion_marcador.png` | Líneas: evolución del marcador promedio por cuarto |
| `12_yac_por_largo_pase.png` | Barras: YAC promedio según el largo del pase |
